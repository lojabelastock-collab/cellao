# SMM WooCommerce Ultimate Integration

Integração profissional com redes sociais e plataformas SMM para WooCommerce.

## 📋 Requisitos

- WordPress 6.0 ou superior
- PHP 8.0 ou superior
- WooCommerce 7.0 ou superior
- MySQL 5.7 ou superior

## 🚀 Funcionalidades Planejadas

- ✅ Integração com múltiplos providers SMM
- ✅ Sistema de níveis e pontos para clientes
- ✅ Programa de cashback
- ✅ Favoritos/Wishlist
- ✅ Sincronização automática de dados
- ✅ Dashboard administrativo completo
- ✅ API REST customizada

## 📁 Estrutura de Diretórios

```
smm-woocommerce-ultimate-integration/
├── admin/                 # Componentes administrativos
├── api/                   # Endpoints REST API
├── assets/               # CSS, JS e imagens
├── background/           # Processamento assíncrono
├── classes/              # Core e autoloader
├── core/                 # Inicialização e segurança
├── frontend/             # Componentes de frontend
├── includes/             # Helpers e utilitários
├── importer/             # Parsers de APIs externas
├── languages/            # Arquivos de tradução
├── modules/              # Módulos independentes
├── providers/            # Integração com providers
├── templates/            # Templates customizáveis
├── uploads/              # Diretório para uploads
├── widgets/              # Widgets e componentes
└── smm-woocommerce-ultimate-integration.php  # Arquivo principal
```

## 🔧 Instalação

1. Clone o repositório em `wp-content/plugins/`
2. Ative o plugin no WordPress
3. Configure as integrações em "SMM Integration" no menu admin
